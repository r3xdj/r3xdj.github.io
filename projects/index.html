🖥️ Software & Tools Development

🛠️ cmd-protocol

一個讓使用者能直接透過瀏覽器網址列（自訂 Protocol Handler）觸發並執行 Windows 系統命令的輕量化工具。

  • GitHub Repository: r3xdj/cmd-protocol
  • 技術棧: Python / Windows Registry
  • 專案簡介: 靈感來自I made my own protocol，由於原影片未提供 C 的程式，我便自己用 Python 做一個。藉由註冊 Windows 登錄檔（.reg）實現了自訂的 cmd:// 協定。當使用者在瀏覽器網址列輸入指令時，會自動調用後端的 Python 執行檔進行 URL Decode，並在跳出安全確認視窗後於本地端執行對應的終端機命令。
