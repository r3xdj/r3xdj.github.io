CSES Exponentiation II 題解

發表於2026-05-31|更新於2026-05-31|OICSESMathematics

本題會用到上次在CSES Exponentiation 題解 | R3X’s Blog講到的東西，並假設讀者都已看過。

題目

  • Time limit: 1.00 s
  • Memory limit: 512 MB

Your task is to efficiently calculate values abca^{b^c}abc modulo 109+710^9+7109+7.
Note that in this task we assume that 00=10^0=100=1.

Input Output
The first input line contains an integer nnn: the number of calculations.
After this, there are nnn lines, each containing three integers a,ba, ba,b and ccc.		 Print each value abca^{b^c}abc modulo 109+710^9+7109+7.

Constraints

  • 1≤n≤2⋅1051 \le n \le 2 \cdot 10^51≤n≤2⋅105
  • 0≤a,b,c≤1090 \le a,b,c \le 10^90≤a,b,c≤109

Example:

Input Output
3
3 7 1
15 2 2
3 4 5
 2187
50625
763327764

解法

這題跟前一題差不多，我們只要額外想如何處裡aaa上面的bcb^cbc即可。因為M=109+7M = 10^9+7M=109+7是質數，所以我們可以用費馬小定理，即aM−1≡1(modM)a^{M-1}\equiv 1\pmod{M}aM−1≡1(modM)。於是我們只要先計算出t≡bc(modM−1)t\equiv b^c \pmod{M-1}t≡bc(modM−1)(這樣能有效的讓aaa的指數變小)，再計算ata^tat即可。指數計算則用我們上次提到的快速冪。
